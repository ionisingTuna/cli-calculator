# cli-calculator

A minimalist command-line calculator app.

## Usage

**Interactive mode:**
```bash
python calculator.py
```

**Command-line mode:**
```bash
python calculator.py "2 + 2"
python calculator.py "10 * (5 + 3)"
python calculator.py 15 / 3
```

## Supported Operations

- Addition: `+`
- Subtraction: `-`
- Multiplication: `*`
- Division: `/`
- Parentheses: `()`
- Decimals: `.`

## Examples

```
> 2 + 2
= 4

> 10 * (5 + 3)
= 80

> 15 / 3
= 5.0
```
